# Бизнес Квест — сайт для бизнес-сообществ, компаний, банков и спонсоров

Русскоязычный сайт **marketgame.quest**: программа деловой игры
**«Бизнес Квест»** (так называется русская версия Market Game) для
бизнес-сообществ и компаний России, которую оплачивает сам организатор или
спонсор (банк). Компания — ООО «АПДЕЙТИНГ СЕРВИС». Главная цель сайта —
заявка на бесплатную демо-игру.

Где на marketgame.biz «chamber of commerce», здесь «сообщество или
компания»; где «Founding Chamber» — «эксклюзивный партнёр региона»
(первая организация региона с договором получает эксклюзивное право
проводить игру в регионе). В коде и файлах данных остались прежние
имена (`chamber`, `chambers.json`, `founding`) — так проще переносить
правки между двумя сайтами.

Это копия [marketgame.biz](https://github.com/ph001player1-lab/MarketGame.biz)
(сайт для США), переведённая на русский и перенесённая на Россию: вместо
51 штата — 83 региона, цены в рублях, вакансии — на hh.ru. Устройство,
страницы и логика те же; про основателя на сайте ничего нет — сайт говорит
от имени компании, контакты — почта и формы заявок. Саму игру сайт не описывает — это делает
[marketgame.club/ru](https://marketgame.club/ru/).
Все продуктовые решения записаны в [CONCEPT.md](CONCEPT.md).

Кроме игры, на сайте есть отдельное направление — **корпоративное обучение
ИИ** (страница `/ai/`, ссылка «Обучение ИИ» в шапке и подвале): пробный
интенсив, корпоративный курс и сопровождение внедрения ИИ в бизнес-процессы.

## Как устроен сайт

Страницы собирает генератор [Eleventy](https://www.11ty.dev/) из шаблонов
и таблиц данных. Главное следствие: **страниц регионов 83, а шаблон один** —
`src/region.njk`. Поправили его — поменялись все регионы сразу. Руками
страницы регионов никто не пишет.

Сборка идёт на GitHub сама, при каждом изменении (см. «Публикация»).
Ставить что-либо на компьютер не нужно: всё правится через веб-интерфейс
GitHub — карандаш на нужном файле → Commit changes.

## Что где менять

| Что меняете | Где |
|---|---|
| Любая цена, опция, цена билета | `src/_data/pricing.json` — одно место на весь сайт, калькулятор и PDF |
| Тексты блоков | нужный файл в `src/_includes/partials/` |
| Тексты страницы региона | `src/region.njk` и блоки, которые он подключает |
| Адрес приёма заявок | `src/_data/site.json` → `formEndpoint` |
| Email | `src/_data/site.json` → `contact` |
| Реквизиты компании | `src/_data/site.json` → `company` (см. ниже) |
| Пометка «Цены указаны без НДС» | `src/_data/site.json` → `vat` |
| День и время открытой игры региона | `src/_data/regions.json` → поле `game` у региона |
| Место региона на карте | `src/_data/regions.json` → поле `tile`: [ряд, колонка], сетка 11 × 16 |
| Отменить открытую игру | `src/_data/schedule.json` → `exceptions` |
| Страница карьеры: тексты вакансий, ссылки hh.ru, оклад и процент, сценарий калькулятора, воронка, плейбук | `src/_data/agents.js` (цены — из `pricing.json`) |
| Обучение ИИ: цены тарифов, длительность, размер группы | `src/_data/ai.json`; тексты страницы — `src/ai.njk` |
| Цвета, отступы, шрифты | `src/assets/css/site.css` |

Цены хранятся **только** в `pricing.json`: карточки, таблицы, калькулятор,
PDF и `llms.txt` берут их оттуда. Поменяли цифру — она поменялась везде.

Все цены — без НДС. Текущие цены: пробная игра 20 000 ₽ (для эксклюзивного партнёра региона 10 000 ₽),
разовая игра 50 000 ₽, годовая программа 300 000 ₽ (25 000 ₽ за игру),
программа банка от 5 сообществ — 250 000 ₽ за каждое в год. Опции: очный
ведущий +15 000 ₽, игра на английском +8 000 ₽, формат «Элита» +25 000 ₽,
игра сверх пакета 25 000 ₽ (20 000 ₽ для банка от 5 сообществ), сертификация
ведущего 40 000 ₽. Билеты — как на marketgame.club/ru: «Старт» 2 000 ₽,
«Рост» 8 500 ₽, «Элита» 250 000 ₽ за команду.

## Вакансии

На странице карьеры `/agents/` — две вакансии отдела продаж: B2B-менеджер
без опыта и B2B-менеджер с опытом (оклад 100 000 ₽ + 15% с каждого
контракта, ориентир дохода 150 000–350 000 ₽ в месяц). У менеджера без
опыта оклада нет: 20% с новых продаж, 20% с продлений и 3 500 ₽ за каждую
игру, которую он проводит ведущим. Тексты вакансий и условия — в
`src/_data/agents.js`; калькулятор дохода на странице считает обе вакансии
на первые 90 дней.

Когда вакансии опубликуете на hh.ru, впишите адреса в тот же файл:

```js
const vacancies = [
  { key: 'junior', …, url: 'https://hh.ru/vacancy/12345678' },
  { key: 'senior', …, url: 'https://hh.ru/vacancy/12345679' }
];
const employer = { url: 'https://hh.ru/employer/1234567' };
```

На карточках появятся кнопки «Открыть на hh.ru», а со страницей
работодателя — ссылка «Все вакансии компании на hh.ru». Отклики с сайта
приходят в лист «Заявки — агенты» таблицы продаж.

## Обучение ИИ

Страница `/ai/` — корпоративное обучение работе с нейросетями для компаний,
которые ещё не начали ими пользоваться. Три платных тарифа (цены — в
`src/_data/ai.json`, без НДС):

| Тариф | Цена | Формат |
|---|---|---|
| Пробный интенсив | 90 000 ₽ | 4 часа, до 20 человек; засчитывается, если курс заказан в течение 30 дней |
| Корпоративный курс | 350 000 ₽ | 4 недели, 8 занятий (16 часов), до 20 человек |
| Сопровождение внедрения ИИ | от 150 000 ₽ в месяц | минимум 3 месяца |

Цены выбраны по рынку корпоративного обучения ИИ в России (осень 2026 года,
цены подрядчиков с их сайтов): короткое занятие или интенсив для группы —
60–170 тыс. ₽, полный день — 120–350 тыс. ₽, корпоративная программа
у крупных школ — 200–600 тыс. ₽ за группу; ИИ-аудит процессов —
72–150 тыс. ₽, пилот на одном процессе — 150–450 тыс. ₽. Сопровождение
на 3 месяца (от 450 тыс. ₽) по объёму — это аудит плюс пилот 2–3
сценариев. Заявки со страницы приходят в лист «Заявки — обучение ИИ».

## Реквизиты компании и персональные данные

Реквизиты ООО «АПДЕЙТИНГ СЕРВИС» — в `src/_data/site.json` → `company`:
наименование, ИНН, КПП, юридический адрес, банк и счета, генеральный
директор. Они показываются на странице `/requisites/`, а наименование, ИНН
и адрес — в подвале, в политике конфиденциальности и в тексте согласия.
Поменяли в одном месте — поменялось везде.

Тексты `privacy.njk` и `consent.njk` стоит показать юристу.

Заявки, как и на marketgame.biz, уходят в Google Таблицы и Telegram —
это серверы за пределами России. По 152-ФЗ данные граждан России при сборе
нужно записывать в базы на территории России; владелец сайта принял текущую
схему, политика конфиденциальности описывает её честно.

## Открытые игры в регионах

Одна открытая онлайн-игра в месяц в каждом регионе, по местному времени.
Расписание не хранится списком, а считается от сегодняшней даты по
правилу региона в `regions.json`:

```json
"game": { "nth": 1, "weekday": 2, "time": "19:00" }
```

`nth` — неделя месяца (1–4), `weekday` — день недели (0 — воскресенье,
2 — вторник), `time` — местное время региона. Сейчас регионы разложены
по 12 слотам (4 недели × вторник, среда, четверг), по 6–7 регионов из разных
поясов в каждом. Если нагрузка велика, регионы одного пояса можно ставить
в один слот и проводить одной игрой.

Отмена — строка в `schedule.json` → `exceptions`:
`"2026-12-31"` — в этот день ничего; `"2026-12-31 TA"` — только Татарстан
(код региона — поле `abbr` в `regions.json`).

Кнопка «Записаться» ведёт на marketgame.club/ru с метками
`utm_campaign=TA` и `utm_content=2026-10-06`: форма заявки на .club их
сохраняет, менеджер увидит регион и дату.

## База сообществ: из таблицы продаж на сайт

Источник правды — Google-таблица продаж **по России** (отдельная от
таблицы marketgame.biz). На сайт попадают только два открытых листа:
**«Сайт — сообщества»** и **«Сайт — банки»**. Их создаёт и отдаёт сайту тот же
скрипт, что принимает заявки (`apps-script/Code.gs`), поэтому ни
публиковать листы, ни заводить что-то в GitHub не нужно.

**Один раз:**

1. Таблица продаж → Расширения → Apps Script.
2. Замените весь код содержимым `apps-script/Code.gs`.
3. Настройки проекта → Свойства скрипта: `BOT_TOKEN` и `CHAT_ID`
   (можно те же бот и группа, что у marketgame.club и marketgame.biz).
4. Выберите функцию `checkSetup` → Выполнить. Она проверит бота и создаст
   все листы: заявки и оба листа для сайта — с заголовками, выпадающими
   списками регионов и статусов и галочками.
5. Развернуть → Новое развёртывание → Веб-приложение, «Запуск от имени: я»,
   «Доступ: все» → Развернуть.
6. Адрес вида `https://script.google.com/macros/s/…/exec` впишите в
   `src/_data/site.json` → `formEndpoint`.

**Дальше — только заполнять строки.** Лист «Сайт — сообщества»:

| Колонка | Что писать |
|---|---|
| Регион | из выпадающего списка: «Республика Татарстан», «Москва»… |
| Сообщество | название сообщества или компании |
| Город, Сайт | по желанию |
| Статус | «Договор подписан» или «Нет договора» |
| Дата договора | для подписанных: самая ранняя дата в регионе = эксклюзивный партнёр региона |
| Публиковать | галочка = организация разрешила показывать свой статус (пункт в договоре) |
| Спонсор | банк или спонсор, если платит он |
| Публиковать спонсора | галочка = спонсор разрешил упоминание |

Без галочки «Публиковать» организация с договором остаётся в списке, но без
статуса. Лист «Сайт — банки»: Регион · Банк · Территория (Регион или Город)
· Город или агломерация · галочки Эксклюзив, Активен, Публиковать.

Наружу уходят только эти колонки — даже если добавить в лист другие
(контакты, суммы), скрипт их не отдаст.

GitHub раз в час забирает листы, обновляет `src/_data/chambers.json` и
`banks.json` (история статусов видна в коммитах) и пересобирает сайт.
Если в таблице ничего не поменялось, сайт не трогается. Запустить сразу:
Actions → Build and deploy → Run workflow. Проверить, что отдаёт скрипт:
откройте `…/exec?sheet=chambers` в браузере.

**Полный список сообществ** (деловые клубы, ассоциации, отделения
«Опоры России» и «Деловой России», отраслевые союзы, ТПП) пока нужно
собрать — он же станет базой для обзвона.

## Статистика регионов и индексация

У каждого региона в `regions.json` есть поле `stats`. Пока оно `null`,
блок цифр не показывается. Формат:

```json
"stats": {
  "smallBusinesses": 120000,
  "employees": 450000,
  "newBusinesses": 25000,
  "newBusinessesYear": 2025,
  "selfEmployed": 300000,
  "smeLoans": 210,
  "smeLoansYear": 2025,
  "sources": "ФНС России (Единый реестр субъектов МСП), Росстат, Банк России"
}
```

Цифры выше — пример формата, а не данные. `smeLoans` — в миллиардах рублей.
Источники: Единый реестр субъектов МСП (rmsp.nalog.ru), статистика
регистраций и самозанятых ФНС, Росстат, статистика кредитования МСП
Банка России. Любое поле можно не заполнять — его строки не будет.

**Пока у региона нет ни статистики, ни списка сообществ, его страница закрыта
от индексации** (`noindex`) и не входит в `sitemap.xml`: 83 почти одинаковые
страницы выглядели бы для поисковиков как дорвеи. Появились данные — страница
открывается сама, при следующей сборке.

## Заявки

Форма демо-игры — одна на три случая (сообщество или компания, банк, спонсор), с разными
полями. Заявка уходит в Google Apps Script, который пишет строку в таблицу
продаж (свой лист для каждого типа) и присылает уведомление в Telegram — так
же, как на marketgame.club. Тем же скриптом идут отклики агентов со страницы
`/agents/` — тип `agent_application`, лист «Заявки — агенты» — и заявки
на обучение ИИ со страницы `/ai/` — тип `ai_training`, лист «Заявки —
обучение ИИ». Заявки сообществ и компаний — в лист «Заявки — сообщества
и компании». Пока в Apps Script стоит старая версия `Code.gs` без типа
`ai_training`, заявки на обучение ИИ попадают в лист сообществ с пометкой
«Обучение ИИ — тариф».

Адрес скрипта вписан в `src/_data/site.json` → `formEndpoint`.

Проверка: откройте адрес `…/exec` в браузере. Должно прийти
`"service":"marketgame-quest-leads"`, `"hasToken":true`, `"hasChatId":true`,
а в `"leadTypes"` — `"agent_application"` и `"ai_training"`.

После любой правки `Code.gs`: Развернуть → Управление развёртываниями →
карандаш → Версия: новая → Развернуть. Адрес при этом не меняется.

## PDF

Три документа, которые сохраняются из браузера как PDF:

| Адрес | Для кого |
|---|---|
| `/print/brief/` | Описание программы — организатор отправляет руководству |
| `/print/prospectus/` | Предложение для спонсора — организатор отправляет банку, со своим названием |
| `/print/bank/` | Описание для банка |

Сверху — поля (сообщество, спонсор, регион, контакт): они подставляются в
документ сразу и сохраняются в адресе страницы, так что заполненный
документ можно переслать ссылкой. Кнопка «Сохранить в PDF» открывает окно
печати, где выбирается «Сохранить как PDF». Формат — A4.

## Публикация

Сайт публикуется на GitHub Pages через GitHub Actions
(`.github/workflows/deploy.yml`) при каждом изменении **основной ветки**
репозитория (Settings → General → Default branch). Изменения в других
ветках на сайт не попадают.

**Один раз в GitHub:** Settings → Pages → Build and deployment → Source:
**GitHub Actions**. Затем Actions → Build and deploy → Run workflow — сайт
соберётся и откроется по адресу вида `ph001player1-lab.github.io/marketgame.quest`
(стили там поедут: сайт рассчитан на корень домена — это нормально,
до подключения домена).

Если публикация падает с ошибкой «Branch … is not allowed to deploy to
github-pages»: Settings → Environments → github-pages → Deployment
branches — добавьте основную ветку.

### Домен marketgame.quest

Сначала домен указывают в GitHub, потом в DNS — так советует GitHub.

1. GitHub → Settings → Pages → Custom domain: `marketgame.quest` → Save.
2. У регистратора домена в DNS: четыре записи типа **A** для самого домена —
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   и запись **CNAME** для `www` со значением `ph001player1-lab.github.io`.

### Почта contact@marketgame.quest

Адрес указан на сайте (`site.json` → `contact.email`). Переадресация на
Gmail настроена у Dynadot так же, как для contact@marketgame.biz (MX —
`parkmail.dynadot.com`). Проверяйте письмом с другого адреса: письмо от
себя самого Gmail не покажет.

### Яндекс

В России основной поисковик — Яндекс. После публикации добавьте сайт в
[Яндекс Вебмастер](https://webmaster.yandex.ru/) и укажите `sitemap.xml`.
В `robots.txt` для Яндекса уже есть `Clean-param`: метки кампаний не
плодят дубли страниц.

GitHub отключает расписание в репозиториях без активности 60 дней —
тогда раз в час обновление остановится. Включается обратно кнопкой в
Actions.
